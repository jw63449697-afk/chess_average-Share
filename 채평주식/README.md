# 채평주식 Discord Bot

Discord 서버에서 지정된 UP/DOWN 스티커로 공통 주가를 움직이고, 레이트로 주식을 거래하는 봇입니다.

## Altare에 배포하기

이 프로젝트는 Node.js 20 이상과 `npm start`로 실행됩니다. Altare의 Bot Hosting에서 Node.js 서버를 만들면 됩니다. 이 봇은 Discord Gateway에 직접 연결하므로 공개 HTTP 포트나 핑용 웹 서버가 필요하지 않습니다.

1. Altare Console에서 **Bot Hosting → Create server → Node.js**를 선택합니다.
2. 메모리는 우선 256~512MB 정도로 설정합니다.
3. 프로젝트 파일을 ZIP 또는 파일 매니저/SFTP로 업로드합니다. `node_modules`는 업로드하지 않습니다.
4. Startup 명령을 `npm start`로 설정합니다. (또는 `package.json`의 start 스크립트를 실행하도록 설정)
5. 환경 변수에 아래 값을 설정합니다.
   - `DISCORD_TOKEN`: Discord 봇 토큰
   - `DISCORD_APPLICATION_ID`: Discord 애플리케이션 ID
   - `DATABASE_PATH`: `./data/chaepyeong.sqlite` (선택 사항, 기본값)
   - `DISCORD_GUILD_ID`: 개발 중 특정 서버에 명령어를 빠르게 등록할 때만 사용
6. 서버를 시작하고 Console 로그에서 `Logged in as ...`가 표시되는지 확인합니다.
7. 슬래시 명령어가 아직 등록되지 않았다면 Altare Console에서 한 번 `npm run register`를 실행하거나, 로컬 PC에서 같은 환경변수로 실행합니다.

**중요:** 같은 Discord 봇 토큰으로 이 봇을 두 인스턴스에서 동시에 실행하지 마세요. 한 인스턴스만 실행해야 중복 처리와 데이터 충돌을 피할 수 있습니다.

## 데이터 저장

기본 데이터베이스는 `./data/chaepyeong.sqlite`입니다. 이 프로젝트는 `sql.js`로 SQLite 파일을 읽고 변경 내용을 디스크에 저장합니다. Altare의 봇 서버 한 개에서 실행하는 구성을 전제로 합니다. 서버를 삭제하거나 저장 디스크가 초기화되면 데이터가 사라질 수 있으므로, 중요한 데이터는 주기적으로 백업하세요.

이 버전은 Supabase/Firebase 연결을 요구하지 않습니다. Altare에서 제공하는 Managed PostgreSQL로 이전할 필요도 없습니다.

## 로컬 실행

1. `npm install`
2. `.env.example`을 `.env`로 복사하고 Discord 값을 입력합니다.
3. `npm run register`로 슬래시 명령어를 등록합니다.
4. `npm start`로 봇을 실행합니다.

## 명령어

- `/현재주가` — 현재가, 시작가 대비 변동률, 최근 5회 변동
- `/매수 금액` — 입력 금액에 맞춰 정수 주식 수를 매수합니다. 반올림하되 입력 금액을 넘는 매수는 하지 않습니다.
- `/매도 수량` — 보유 주식을 현재가로 매도합니다.
- `/채평주식보유량` — 보유량과 현재 평가액
- `/레이트확인` — 레이트 잔액
- `/출석체크` — 한국 시간 기준 하루 한 번 600레이트 지급
- `/랭킹` — 총자산(레이트 잔액 + 보유 주식의 현재 평가액) 기준 본인 순위와 상위 5명

새 계정의 기본 잔액은 5,000레이트이며, 시작 주가는 500레이트입니다.

## 스티커 주가 변동

서버 내 메시지의 지정된 스티커 ID와 이름이 함께 일치하면 UP은 +3~+6%, DOWN은 -2~-4% 범위의 변동률을 무작위 적용합니다. 매회 반올림한 정수 가격을 저장하고, `/현재주가`에는 최근 5회 기록을 오래된 순서부터 표시합니다. 메시지 ID로 중복 처리를 방지하며, 별도의 채팅 알림은 보내지 않습니다.
